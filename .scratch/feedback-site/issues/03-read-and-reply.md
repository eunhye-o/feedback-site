# 03: 피드백 열기와 답글 (핵심 장면 3)

**What to build:** 학생이 피드백을 열고 답글 한 줄을 남기면, 선생님 화면의 학생 이름 옆에 읽음과 답글이 표시된다.

**Blocked by:** 02 (피드백 쓰기)

**Status:** ready-for-agent

- [ ] 하늘 화면에서 피드백은 처음에 접혀 있고, "피드백 열기"를 누르면 피드백 내용이 보인다.
- [ ] 피드백을 열기 전에는 선생님 화면의 하늘 옆에 "안 읽음"이, 연 뒤에는 "읽음"이 보인다.
- [ ] 피드백을 연 뒤에 답글 칸이 보이고, 답글 한 줄을 보내면 하늘 화면에 그대로 보이며 다시 고칠 수 없다.
- [ ] 선생님 화면의 하늘 옆에 "답글"이 보이고, 하늘을 열면 답글 내용이 보인다.
- [ ] 브라우저를 새로 고쳐도 읽음과 답글이 그대로 남아 있다.
