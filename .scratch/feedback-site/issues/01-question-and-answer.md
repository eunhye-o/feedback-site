# 01: 질문 올리기와 답 내기 (핵심 장면 1)

**What to build:** 사이트의 뼈대와 핵심 장면 1을 만든다. 처음 화면에서 "학생 / 선생님"을 고르고, 선생님은 비밀번호를 입력해 들어간다. 학생은 반·번호를 입력하고, 처음이면 4자리 비밀번호를 직접 정하고 다음부터는 그 비밀번호로 들어간다(명단과 선생님 비밀번호는 spec.md의 "들어가는 방법" 참고). 선생님이 오늘의 질문을 올리면 학생 화면에 질문이 보이고, 학생이 자기 말로 쓴 답과 어려웠던 점은 선생님 화면의 학생 목록에 모인다. 모든 기록은 브라우저에 저장된다.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 처음 화면에서 "학생"과 "선생님" 중 하나를 고를 수 있고, 학생을 고르면 반과 번호를 넣는 칸이 보인다.
- [ ] 명단에 없는 반·번호(예: 2반 1번)를 넣으면 안내 문구가 보이고 다음으로 넘어가지 않는다.
- [ ] 1반 1번을 처음 넣으면 "비밀번호 정하기" 칸 두 개가 보인다. 숫자 4자리가 아니거나 두 칸이 다르면 안내 문구가 보이고, 맞게 정하면 "1반 1번 하늘" 학생 화면으로 들어간다.
- [ ] 다시 1반 1번을 넣으면 비밀번호 칸 하나만 보이고, 틀린 비밀번호면 안내 문구가 보이며 들어가지 않는다. 정한 비밀번호를 넣으면 들어간다.
- [ ] "선생님"을 고르면 비밀번호 칸이 보이고, 틀린 비밀번호를 넣으면 안내 문구가 보이며 선생님 화면에 들어가지 않는다.
- [ ] 처음 열었을 때 학생 화면에 미리 넣어 둔 질문("오늘 수업에서 배운 전류와 전압은 어떻게 다른가요? 친구에게 설명하듯 내 말로 2~3문장 써 보세요.")이 보인다.
- [ ] 선생님 화면에서 새 질문을 올리면, 학생 화면에 새 질문이 보이고 이전 답들은 사라진다.
- [ ] 학생 화면에서 답 칸을 비우고 내면 안내 문구가 보이고 제출되지 않는다.
- [ ] 하늘로 답과 어려웠던 점을 내면, 하늘 화면에 내가 쓴 글이 그대로 보이고 다시 고칠 수 없다.
- [ ] 선생님 화면의 학생 목록에서 하늘 옆에 "제출", 아직 안 낸 학생 옆에 "미제출"이 보인다.
- [ ] 선생님 화면에서 하늘 이름을 누르면 하늘의 답과 어려웠던 점이 보인다.
- [ ] 학생 화면에는 학생 목록이나 다른 학생의 글이 보이지 않는다.
- [ ] 브라우저를 새로 고쳐도 질문과 낸 글이 그대로 남아 있다.
