# 04: 안 읽은 학생과 답글 온 학생 모아 보기 (핵심 장면 4)

**What to build:** 선생님이 선생님 화면에서 학생을 모아 보면, 아직 피드백을 읽지 않은 학생과 답글이 온 학생만 보인다. 학생 목록 위의 켜고 끄는 버튼 하나로 동작한다.

**Blocked by:** 03 (피드백 열기와 답글)

**Status:** ready-for-agent

- [ ] 선생님 화면의 학생 목록 위에 "모아 보기" 버튼이 보인다.
- [ ] 버튼을 켜면 아직 피드백을 읽지 않은 학생과 답글이 온 학생만 목록에 남는다.
- [ ] 피드백을 읽었고 답글이 없는 학생은 버튼을 켜면 목록에서 사라진다.
- [ ] 버튼을 다시 누르면 학생 5명이 모두 다시 보인다.
