# 05: 학생 비밀번호 초기화

**What to build:** 선생님이 선생님 화면에서 학생 이름을 열어 그 학생의 비밀번호를 초기화하면, 그 학생은 다음에 들어올 때 비밀번호를 새로 정한다. 학생이 비밀번호를 잊어버렸거나 다른 친구가 먼저 정해 버렸을 때 쓴다. (PRD "대상"의 "들어가기" 줄)

**Blocked by:** 01 (질문 올리기와 답 내기)

**Status:** ready-for-agent

- [ ] 선생님 화면에서 학생 이름을 누르면 "비밀번호: 정해 둠" 또는 "비밀번호: 아직 안 정함"이 보인다.
- [ ] 비밀번호를 정해 둔 학생에게만 "비밀번호 초기화" 버튼이 보인다.
- [ ] "비밀번호 초기화"를 누르면 한 번 더 묻는 창이 뜨고, "취소"를 누르면 아무것도 바뀌지 않는다.
- [ ] "확인"을 누르면 "비밀번호: 아직 안 정함"으로 바뀐다.
- [ ] 초기화한 학생으로 반·번호를 넣으면 비밀번호를 새로 정하는 칸 두 개가 보이고, 예전 비밀번호로는 들어갈 수 없다.
- [ ] 초기화한 뒤에도 그 학생이 낸 답과 어려웠던 점은 학생 화면과 선생님 화면에 그대로 보인다.
- [ ] 브라우저를 새로 고쳐도 초기화된 상태가 그대로 남아 있다.
